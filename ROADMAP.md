# Roadmap

OpenVPN Manager is currently an early-stage Windows desktop application.
Priorities may change based on testing and security findings.

## Near term

- Validate the first public release on a clean Windows Server system.
- Improve diagnostics for OpenVPN startup and status failures.
- Add controlled certificate revocation and CRL deployment support.
- Add end-to-end tests for the guided setup workflow.

## Later

- Evaluate optional executable code signing.
- Add import and migration tools for existing branch inventories.
- Improve accessibility and keyboard navigation.
- Document backup and restore procedures for application data.

Private key handling, confirmation for productive changes, and recoverable PKI
operations remain non-negotiable constraints.
